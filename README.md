# Vidrio Roca S.R.L.

Sitio institucional estático, sin dependencias de compilación. Abrir `index.html` en un navegador o servir esta carpeta con cualquier servidor web estático.

## Antes de publicar

- Reemplazar `WHATSAPP_NUMBER` en `app.js` por el número comercial en formato internacional, sin `+` ni espacios. El valor actual es un marcador seguro de desarrollo y no envía consultas.
- Confirmar o sustituir `info@vidrioroca.com`.
- Cargar la URL oficial de Instagram.
- Confirmar el listado final de servicios, tipos de vidrio, líneas de aluminio y proceso de trabajo.
- Sustituir `hero-temporal.png` y los espacios reservados de proyectos por fotografías propias autorizadas. La imagen actual es una referencia generada y está identificada como temporal en la interfaz.
- Incorporar los logos de clientes o marcas sólo con autorización y archivos correspondientes.
- Entregar el archivo original del logo provisto como `logo-vidrioroca.png`; el diseño actual evita reconstruir o modificar ese arte hasta recibir el asset exportable.

## Referencias de investigación

Se revisaron los repositorios de Colorlib, Interrio y Glass UI. Colorlib e Interrio declaran licencia MIT; no se copió código ni fotos de esos proyectos. El enfoque visual adopta sólo ideas generales: jerarquía editorial de proyectos, grilla de servicios y uso moderado de transparencias. Glass UI es un proyecto Next.js y sus dependencias no se incorporaron en este sitio estático.
